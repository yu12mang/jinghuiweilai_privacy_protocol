您使用或继续使用我们的服务，即意味着您理解并同意鲸惠未来按照本《隐私协议》收集、使用、储存和分享您的相关信息。

一、我们可能收集的信息

我们提供服务时，可能会在合法、正当、必要的范围内收集、储存和使用下列与您有关的信息。如果您不提供相关信息，可能无法享受我们提供的某些服务，或者无法达到相关服务拟达到的效果。

（一）您提供的信息

1. 您在注册、登录、使用服务、联系客服、提交反馈、参加活动或办理售后时，可能向我们提供账号信息、昵称、头像、手机号、电子邮箱、账号 ID、反馈内容、沟通记录、问题截图或相关证明材料。

2. 如应用提供订单、会员、兑换、售后、退款或其他交易功能，您可能需要提供订单编号、购买记录、服务记录、支付状态、发票信息及售后信息。支付账户、银行卡号等敏感支付信息通常由合规支付服务商处理。

3. 您主动上传或填写的内容，例如图片、评论、表单、活动报名信息及其他由您主动提供的信息。

（二）我们获取的您的信息

您使用服务时，我们可能根据具体功能收集如下信息：

1. 设备与应用信息，包括设备型号、操作系统版本、应用版本、设备标识符、网络类型、运营商信息、语言设置、屏幕参数及应用安装来源。

2. 日志信息，包括访问时间、页面浏览记录、点击记录、崩溃日志、性能数据、错误日志、IP 地址及系统诊断信息。

3. 权限相关信息，包括相机、相册、存储、定位、蓝牙、麦克风、通知等系统权限。我们仅会在您授权后访问相关权限，并用于授权时说明的具体目的。

4. 位置信息，当您开启定位并使用基于位置的功能时，我们可能通过 GPS、WLAN、蓝牙或基站等方式获取您的大致或精确位置信息。您可以通过关闭定位功能，停止对地理位置信息的收集。

5. 第三方来源信息，在您授权第三方服务向我们共享信息，或法律法规允许的情况下，我们可能从第三方获取您授权共享的信息，并会确认其来源合法性。

二、我们可能如何使用信息

我们可能将在向您提供服务的过程之中所收集的信息用作下列用途：

1. 向您提供应用基础功能、账号登录、身份验证、客户服务、订单处理、售后支持及您主动请求的服务。

2. 在我们提供服务时，用于安全防范、异常检测、诈骗监测、身份核验、日志审计、存档和备份，确保我们向您提供的产品和服务的安全性。

3. 帮助我们设计新服务，改善现有服务，进行故障排查、性能优化、数据统计、用户体验分析和新功能研发。

4. 使我们更加了解您如何接入和使用服务，从而回应您的个性化需求，例如语言设定、位置设定、帮助服务和相关提示。

5. 完成软件认证、服务管理、软件升级、平台审核、争议处理、监管配合和权利保护。

6. 在您同意或法律允许的范围内，向您发送服务通知、功能更新、安全提醒、活动信息或与用户权益相关的信息。

我们不会将个人信息用于与收集目的无关的用途。如确需改变处理目的，我们会依法再次取得您的同意。

三、您如何访问和控制自己的个人信息

我们将尽合理努力采取适当的技术和管理措施，保障您可以访问、更新、更正、删除自己的个人信息，或撤回已经授权的系统权限。在访问、更新、更正和删除前述信息时，我们可能会要求您进行身份验证，以保障账号和信息安全。

您可以通过应用内设置、设备系统权限管理、客服或本协议提供的联系方式管理个人信息。关闭或撤回某些权限后，相关功能可能无法继续使用，但不会影响其他无关功能。

四、我们可能分享的信息

除以下情形外，未经您同意，我们不会与任何第三方分享您的个人信息，也不会出售您的个人信息：

1. 获得您的明确同意或授权后，按照授权范围共享相关信息。

2. 为实现必要功能，与云服务、数据分析、崩溃统计、消息推送、地图定位、支付、客服、内容审核等服务提供商、承包商或代理共享必要信息。

3. 与我们的关联方共享必要信息，以便提供统一的服务、客户支持、安全保障或合规管理。关联方如需改变处理目的，将依法再次征求您的授权同意。

4. 根据法律法规、司法机关、行政机关或监管部门要求，提供必要信息。

5. 为维护用户、鲸惠未来、合作伙伴或公众的人身财产安全、合法权益、社会公共利益而合理必要。

6. 如发生合并、分立、收购、资产转让、破产清算或类似交易，相关信息可能作为交易的一部分转移，我们会要求新的持有方继续遵守本协议。

如果应用集成第三方 SDK，第三方 SDK 可能根据其功能收集设备信息、网络信息、日志信息、位置信息或其他必要数据。我们会尽合理努力审查第三方 SDK 的数据处理行为，并在应用内或相关说明中披露具体 SDK 名称、用途和数据类型。

五、信息安全

我们仅在实现本协议所述目的所必需的期限内，以及法律法规要求或允许的期限内保留您的个人信息。超过保留期限后，我们会删除或匿名化处理相关信息。

我们使用合理的安全技术和管理程序保护您的信息，防止信息丢失、不当使用、未经授权访问、披露、修改或损坏。这些措施可能包括访问权限控制、传输加密、数据备份、日志审计、安全培训和供应商安全评估。

请您理解，由于互联网环境并非绝对安全，即使我们尽力加强安全措施，也无法保证信息始终百分之百安全。若发生个人信息安全事件，我们将依法采取补救措施，并通过应用内通知、邮件、公告或其他合理方式告知受影响用户。

按照适用法律法规和平台规则，您可以依法对个人信息行使以下权利：

1. 访问、更正、补充您的个人信息。

2. 删除个人信息或申请注销账号。

3. 撤回已经授予的权限或同意。

4. 获取个人信息副本，或对自动化决策、定向推送等提出限制或拒绝。

5. 对我们的个人信息处理活动提出疑问、投诉或建议。

若应用支持账号注册，您可以通过应用内相关入口或本协议提供的联系方式申请删除账号及相关个人信息。收到有效请求后，我们会在合理期限内完成核验、删除或匿名化处理，法律法规另有规定的除外。

我们或我们的第三方合作伙伴，可能通过 Cookie、Web Beacon、SDK、应用日志或类似技术收集和使用您的信息，并将该等信息储存为日志信息。

八、我们可能向您发送的邮件和信息

我们可能在必要时向您发送与服务有关的公告，例如系统维护、服务变更、安全提醒、账号通知或交易状态通知。该类信息属于服务必要通知，可能无法取消。

对于营销或活动类信息，我们将在符合法律要求的前提下发送，并提供合理的退订或关闭方式。

我们鼓励父母或监护人指导未成年人使用我们的服务。未成年人在提交个人信息前，应当取得父母或监护人的同意和指导。

对于经监护人同意而收集儿童个人信息的情况，我们只会在法律允许、监护人明确同意或保护儿童所必要的范围内使用、共享、转让或披露相关信息。如果我们发现未在事先获得可验证的监护人同意的情况下收集了儿童个人信息，将尽快删除相关数据。

十、您的个人信息存储与跨境转移

原则上，我们在中华人民共和国境内收集和产生的个人信息，将存储在中华人民共和国境内。如因业务需要或用户主动使用跨境服务，确需向境外传输个人信息，我们会按照适用法律法规要求履行相应程序，并采取必要安全保护措施。

我们会根据数据类型、处理目的、法律要求和业务需要确定保留期限。账号信息通常保留至账号注销或服务终止后法律要求的必要期限；交易、财务、审计和合规记录会根据法律要求保存必要期限；日志和统计信息会在完成安全、排查、统计或产品改进目的后删除或匿名化。
